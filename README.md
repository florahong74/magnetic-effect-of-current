# 전류의 자기 작용 — 1차시 탐구 수업 자료

중학교 2학년 과학 **Ⅶ. 전기와 자기 — 3. 전류의 자기 작용** 단원을 1차시(45분) 동안 수업할 수 있는 HTML 자료입니다.
설치 없이 브라우저에서 바로 열 수 있고, 휴대폰·태블릿·크롬북에서도 사용할 수 있습니다.

## 구성

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 생각 열기 | 5분 | 핵심 질문: "전동기를 더 빨리 회전하게 하려면?" |
| ② 탐구 1 | 12분 | 전류가 흐르는 코일 주위의 자기장 — 나침반·클립·자기력선, 오른손 법칙 |
| ③ 탐구 2 | 10분 | 자기장 안에서 전류가 흐르는 코일이 받는 힘 — 그네형 코일과 자석 |
| ④ 탐구 3 | 10분 | 전동기의 원리 — 정류자, 전류·자석 세기와 회전 속도 |
| ⑤ 확인 문제 | 6분 | 6문항 자기 점검 |
| ⑥ 정리 | 2분 | 핵심 질문에 근거를 들어 답하기 |

## 사용 방법

- 온라인: GitHub Pages 주소로 접속
- 오프라인: `index.html` 파일을 내려받아 브라우저로 열기

학생이 적은 내용은 각자의 브라우저에만 저장되며 서버로 전송되지 않습니다.
